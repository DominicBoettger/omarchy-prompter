# Welcome

This is your teleprompter. Scripts are plain Markdown files in
~/.local/share/omarchy-prompter/scripts — edit them with any editor.

Headings like the one above become chapters. Jump between them with the
panel buttons or with omarchy-shell prompter nextChapter.

# Controls

Play and pause from the panel, a keybinding, or a Stream Deck button.
Adjust the speed live while you read — the remaining time in the corner
updates with it.

# Pro tip

Flip the text for the beam-splitter glass in the panel under
"Flip for glass". Have a great recording!
